# 球台模型制作与导出

## 文件与保留策略

- 当前源文件：`assets/models/billiards_table.blend`。
- 网页加载：`public/models/billiards_table.glb`。

源文件中的成品集合为 `Refined_Table`，历史模型集合保持隐藏。效果确认后，旧版独立工程、备份、GLB 和一次性 Blender 脚本已清理。后续直接编辑当前源文件。

## 修改与导出

首次在新克隆中维护 Blender 源文件时，执行 `git lfs install --local --skip-repo`。导出和暂存后用 `git lfs ls-files` 确认 `assets/models/billiards_table.blend` 显示为 LFS 对象；预览渲染与 `.blend1` / `.blend.bak` 自动备份均已忽略。

1. 打开当前源文件，编辑 `Refined_Table` 集合并保存。
2. 仅选择该集合内的全部对象，包括六个 `PocketTarget_*` 空对象。
3. 导出 glTF 2.0，格式选择 GLB，启用“仅选中对象”和“应用修改器”；不导出摄影机和灯光。
4. 覆盖 `public/models/billiards_table.glb`，在网页中检查材质、袋口位置及横竖屏显示。发布前重新运行 `pnpm run build`。

不要导出演示球、演示地面或隐藏的历史模型集合。

## 几何与坐标约定

Blender 使用 Z-up，glTF 导出自动转成 Three.js 的 Y-up。台呢高度为 `0.155`，球心高度 `0.655`，球半径 `0.5`。

| 部位 | Blender 坐标 | Three.js 坐标 |
| --- | --- | --- |
| 角袋 | `(±3.25, ±5.45, 0.655)` | `(±3.25, 0.655, ∓5.45)` |
| 中袋 | `(±3.48, 0, 0.655)` | `(±3.48, 0.655, 0)` |

每个袋口包含 `PocketTarget_*` 空对象。Three.js 读取六个对象的坐标作为进球动画目标，避免模型与代码重复维护位置。程序化降级球台继续使用旧袋口坐标。

台呢和石板使用一致的袋口切割；库边收进开口，角部铸件采用圆角外轮廓；皮革为有厚度变化的卷边，缝线和菱形网袋为真实几何；深处衬底遮挡过亮的网格。固定球阵和缩小入袋动画仍是记球界面表达，不是物理台球模拟。

## 材质与网页渲染

- 低对比纵向木纹图像、台呢法线、皮革法线均通过 GLB 携带。
- PBR 材质分别控制木漆、旧黄铜、台呢、皮革与绳网，无需自定义整套 shader。
- 网页使用顶棚反射、主光投影、较弱桌沿补光和透明接影地面（透出页面绿色渐变）。
- 摄影机保留横屏较低、竖屏较高的角度，DOM 热区继续跟随球的投影。
- 本轮资源约 3.4 MB、7.3 万三角面；手机浏览器尺寸检查不能代替 iOS/Android 真机帧率测试。
